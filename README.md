Protótipo web de um jogo de pôquer estilo Texas Hold'em, desenvolvido com foco em interface, experiência visual e apresentação de regras e mecânicas do jogo.

---

## Visão Geral

Este repositório reúne uma base front-end para um protótipo de poker, com estrutura organizada para separar:

- a página principal;
- os estilos visuais;
- os arquivos de suporte;
- versões/variações de layout ou implementação.

A estrutura do projeto sugere que ele foi pensado como uma simulação visual e estudantil, com foco em apresentação e interação inicial do jogo.

---

## Tecnologias Utilizadas

| Tecnologia | Uso |
| --- | --- |
| HTML | Estrutura da interface e conteúdo da página |
| CSS | Estilização, layout, cards, cores e aparência visual |
| JavaScript (em arquivos de suporte, se houver) | Possível lógica de interação e animações |

> Como o repositório é majoritariamente HTML/CSS, a abordagem parece ser um protótipo front-end leve, sem dependências complexas.
